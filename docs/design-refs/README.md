# Referências de design

Joga aqui as imagens (PNG/JPG/WEBP) que servem de inspiração para a UI.
Use nomes descritivos: `home-dashboard-duolingo.png`, `lesson-card-khan.jpg`, etc.

Para conversar com o Claude, basta citar o caminho:

> "olha em `docs/design-refs/home-dashboard.png`, quero algo parecido"

## Commitar ou não?

Por enquanto está tracked. Se virar bagunça (muitas imagens grandes, refs efêmeras),
adicione ao `.gitignore`:

```
docs/design-refs/*
```
